Vi kalder differentialkvotienten for den afledede funktion, og den betegnes med \(f'(x)\) eller \(\frac{dy}{dx}\) eller $\frac{df(x)}{dx}$

Hvor $f'(x_0)$ bare er et tal, er \(f'(x)\) en funktion, som kan bestemmes for alle x tilhørende Dm.

Vi kan se på de interaktive eksempler i kapitlet, og se hvordan differentialkvotienten ændrer sig, når vi ændrer på x.



| Notation | 1. afledede | 2. afledede | Bruges typisk til |
| :--- | :--- | :--- | :--- |
| **Lagrange** | $f'(x)$ eller $y'$ | $f''(x)$ eller $y''$ | Almindelig funktionsanalyse (gymnasiet). |
| **Leibniz** | $\frac{dy}{dx}$ eller $\frac{df(x)}{dx}$ | $\frac{d^2y}{dx^2}$ eller $\frac{d^2f(x)}{dx^2}$ | Kædereglen og differentialligninger. |
| **Newton** | $\dot{x}$ | $\ddot{x}$ | Fysik $($differentiering mht. tid $t)$. |
| **Euler** | $D_x f$ | $D_x^2 f$ | Differentialoperatorer og lineær algebra. |
| **Partiel** | $\frac{\partial f}{\partial x}$ | $\frac{\partial^2 f}{\partial x^2}$ | Funktioner af flere variable. |
