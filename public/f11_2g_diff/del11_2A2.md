**Eksempel på argumentation...**

Man skal huske at være helt præcis, når det gælder grænseværdier, derfor følger her et eksempel på en gylddig argumentation ifm. omskrivning af grænseværdier:

Obs: for at lave ligningerne mere overskuelige har jeg valgt følgende: $f(x+h)$  skrives som fd, $g(x+h)$ skrives som gd, $g(x)$ skrives som g og $f(x)$ skrives som f. Grænseværdien af et udtryk af h, hvor h går mod 0 skrives lim(...)


**Ligning 1:** $ lim ( ( fd * gd - f * g )/h )         =  g * lim(( fd - f )/h )   + f  * lim( ( gd - g )/h )  $

Og selvfølgelig:

$ lim(g) = g $ 

Dvs. ligning 2 nedenfor er identisk med ligning 1

**Ligning 2:** $ lim ( ( fd * gd - f * g )/h )         =  lim(  g) * lim(( fd - f )/h )   + lim ( f ) * lim( ( gd - g )/h )  $

Da $lim(gd) = lim(g)$ er kan nu skrives:

**Ligning 3:** $ lim ( ( fd * gd - f * g )/h )         =  lim( gd ) * lim(( fd - f )/h )   + lim ( f ) * lim( ( gd - g )/h )  $

Husk regnereglerne for grænseværdier: 

$lim(A * B ) = lim(A) * lim(B) $

$ lim(A + B) = lim(A) + lim(B) $

Derfor kan ligning 3 omskrives til:

**Ligning 4:** $ lim ( ( fd * gd - f * g )/h )         =  lim( (( fd - f )*gd    + f * ( gd - g ))/h )  $

Og vi kan nu reducere ligning 4 til følgende :

**Ligning 5:** $ lim ( ( fd * gd - f * g )/h )         =  lim( (( fd*gd - f *gd    + f * gd - g * f ))/h )  $


Og det ses at :

**Ligning 6:** $ lim ( ( fd * gd - f * g )/h )         =  lim( (( fd*gd  - g * f ))/h )  $
